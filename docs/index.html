FREQUENTLY ASKED QUESTIONS

常见问题解答

关于系统要求、安全性、权限与运行机制的解答。

运行 Codex Beacon 的最低系统要求是什么？
操作系统要求 Windows 10 1809 (Build 17763) 或更高版本（推荐 Windows 11 最新版），仅支持 x64 架构。使用“便携免安装版 (Portable)”无需额外安装环境，解压即可运行。
运行此软件会读取或泄露我的 OpenAI API Key 吗？
绝对不会。Codex Beacon 在代码和架构层面实行零凭据保护（Zero-Credential Policy）。诊断程序仅探测进程命令行中的服务标识、已监听端口和网络 IP 归属，严格禁止读取、打印、记录或上传任何 API 密钥、Token 或模型交互文本。
启动时出现 Windows SmartScreen 提示如何处理？
由于本项目是社区开源项目且未购买昂贵的商业代码签名证书，Windows SmartScreen 可能会提示“已保护你的电脑”。点击“更多信息”，确认发布者信息后点击“仍要运行”即可。所有源代码均在 GitHub 开放审计。
为什么某些按钮带有 🛡️ 盾牌图标？
带有 🛡️ 图标的操作（如安装 Windows 服务、修改系统计划任务等）需要 Windows 管理员特权 (UAC Elevation)。点击后会弹出标准的 Windows 用户账户控制授权对话框，属于正常安全机制。
安装 OpenCodex 或 Codex Relay 会影响原本的 Codex 配置吗？
不会。扩展组件与核心客户端是严格解耦的，安装可选扩展仅是部署该工具本身，不会私自覆写你的 config.toml 或修改原本指向官方的 model_provider。
